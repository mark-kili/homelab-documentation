# Hardware

## Overview

This document describes the hardware powering my home lab.

The goal of this server is to provide a reliable environment for self-hosting applications, learning Linux system administration, experimenting with Docker containers, and supporting my software development projects.

---

## Primary Server

### Device

HP Victus Gaming Laptop

### Specifications

| Component | Specification |
|-----------|---------------|
| CPU | Intel Core i5 |
| GPU | NVIDIA GeForce RTX 3050 Laptop GPU (6 GB VRAM) |
| Operating System | Ubuntu Server |
| Primary Purpose | Self-hosted services, development, and learning |

---

## Why I Chose This Hardware

This home lab started on my HP Victus gaming laptop. Rather than leaving the laptop underutilized, I decided to repurpose it into a home server to gain hands-on experience with Linux, Docker, networking, and self-hosting.

Using existing hardware allowed me to begin learning without investing in dedicated server equipment. It also provided an opportunity to explore technologies that are commonly used in real-world IT environments.
Another reason for choosing this device was its NVIDIA RTX 3050 Laptop GPU, which makes it suitable for experimenting with locally hosted AI models and GPU-accelerated workloads. 

As my knowledge grows, I plan to expand the server with additional services and AI applications.

This project demonstrates that valuable hands-on experience can be gained by making the most of available resources rather than waiting for specialized hardware.

## Current Usage

The server currently hosts several services, including:

- Docker Engine
- Portainer
- Nginx Proxy Manager
- PostgreSQL
- Immich

Additional services will be deployed as the home lab continues to grow.

## Lessons Learned

Building my home lab on repurposed hardware has shown me that practical experience doesn't require enterprise equipment. With an existing laptop and open-source software, I've been able to build, manage, troubleshoot, and document a self-hosted environment while developing skills in Linux administration, Docker, networking, and infrastructure management.
