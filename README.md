# 🏠 Home Lab Documentation
## Overview

This repository documents the design, deployment, and maintenance of my self-hosted home lab.

I built this project to gain practical experience in Linux system administration, containerization, networking, reverse proxy configuration, self-hosting, and infrastructure management. Rather than relying solely on cloud platforms, this environment allows me to deploy and manage services on my own hardware while documenting the entire process.

This repository serves as both a technical reference and a record of my continuous learning.
